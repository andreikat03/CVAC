# THE APPLICATION.exe — V3 Release Candidate

Arhiva este un site static: `index.html`, `style.css`, `wizard.css`, `wizard.js`, `assets/`, `docs/`.

## Publicare GitHub Pages
1. Deschide repository-ul dedicat candidaturii.
2. Încarcă TOATE fișierele și directoarele din ZIP la rădăcina ramurii publicate, nu ZIP-ul în sine.
3. În Settings → Pages alege Deploy from a branch și rădăcina `/`.
4. Deschide URL-ul public într-o fereastră privată, verifică cinci capitole, PDF-urile, video și linkul de programare.
5. Repetă testul pe telefon, inclusiv Back/Forward al browserului.

Versiune: `AF-V3-RC-20261115`. Pentru detalii: `QA_V3.md` și `QA_V3.json`.

# THE APPLICATION.exe — Două idei pentru A.R.T. FUSION

Deschide `index.html` într-un browser local sau încarcă **toate fișierele și folderele din acest pachet** în rădăcina repo-ului GitHub Pages (`main / root`). Nu încărca doar fișierul HTML: sunt necesare `wizard.js`, `wizard.css`, `style.css`, `assets/` și `docs/`.

Secțiunea **03 / DOUĂ PROPUNERI** conține două taburi. La Ideea #1, butoanele selectează între 3 bonuri demonstrative și actualizează textele/sursele. La Ideea #2, „CONTACTEAZĂ-NE” este un element vizual de concept (nu un formular live și nu un serviciu oferit de ONG).

Prototipul nu constituie o campanie aprobată sau derulată de A.R.T. FUSION. Datele din exemplarele de bon sunt descrise ca rezultate documentate, fără atribuirea unor impacturi nemăsurate. Contactul din secțiunea finală este contactul candidatului, nu al ONG-ului.

Publicarea nu a fost făcută automat. Pentru instrucțiuni suplimentare vezi `README_PUBLICARE.md`.
